# FPGA‑LLM硬件加速器项目中期进度报告
## 一、项目整体进展
本项目围绕基于FPGA的轻量化大语言模型推理加速系统开展设计，目前已完成前期文献计量调研、检索式构建、文献数据清洗、样本统计分析；完成项目整体需求分析、总体架构设计、硬件模块划分与Verilog代码编写，已实现分模块时序仿真验证，整体进度符合预期。

## 二、已完成工作
1. 文献计量部分：完成中英文检索式搭建、文献样本筛选、数据清洗、基础统计与图表整理，明确领域研究热点与技术方向。
2. 方案设计部分：完成功能、性能、环境、约束四大需求分析，确定四层模块化硬件整体架构。
3. 代码开发部分：完成顶层模块、矩阵运算加速模块、数据缓存模块、激活函数模块等核心代码编写。
4. 仿真验证部分：完成子模块独立仿真与系统级联合仿真，验证逻辑功能与时序稳定性。
5. 仓库建设部分：规范搭建项目文件结构，完成文档分类整理，对齐结题交付格式标准。

## 三、现存问题
1. 部分模块时序裕量偏小，高速数据连续传输时存在潜在时序风险。
2. 串口交互功能暂未完全完善，上位机数据交互有待调试。
3. 硬件上板实测尚未开展，缺少实际运行性能数据。

## 四、后期工作计划
1. 优化代码时序，完善串口通信模块，提升系统稳定性。
2. 完成FPGA开发板上板调试，采集实际运行数据、整理性能对比图表。
3. 完善全部结题文档，完成答辩PPT制作。
4. 整体项目复盘，整理完整项目成果，完成最终结题交付。
