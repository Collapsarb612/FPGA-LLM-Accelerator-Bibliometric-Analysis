# FPGA-LLM硬件电路与模块设计
## 1. 顶层模块设计
顶层模块作为项目总入口，负责接收全局时钟、复位信号，统一调度所有子模块的使能信号与数据信号，统筹整体运行状态，实现模块间的时序同步与数据交互，是整个加速器的控制核心。

## 2. 核心运算模块设计
针对大模型推理中使用频率最高的矩阵乘法运算，设计并行多通道乘加运算单元，拆分运算步骤，采用流水线架构实现连续计算，大幅提升数据吞吐效率，是本项目的核心加速单元，直接决定整体推理性能。

## 3. 存储缓存模块设计
搭建片内分布式缓存单元，用于临时存放模型权重参数与实时输入词向量数据，通过寄存器组实现高速读写，减少频繁读取外部存储带来的延迟，优化数据传输效率。

## 4. 外设交互模块设计
预留串口通信逻辑模块，实现FPGA与电脑上位机之间的数据双向传输，完成指令下发、输入数据接收、推理结果回传，方便后期调试与结果查看。

## 5. 时序电路设计
统一全局工作时钟频率，采用同步复位电路设计，规避亚稳态问题；合理规划组合逻辑路径长度，减少信号延迟，保证整个硬件系统长时间稳定运行，满足时序收敛要求。
