# FPGA-LLM硬件加速器总体方案设计
## 1. 整体设计架构
本项目采用模块化分层设计思想，将整个LLM加速器划分为顶层控制层、运算加速层、数据存储层、通信交互层四层结构，层与层之间信号交互简洁，独立调试互不干扰，具备良好的可维护性与拓展性。
- 顶层控制层：统筹全系统运行时序，实现模块间状态同步与调度
- 运算加速层：承载LLM推理核心运算，实现并行计算加速
- 数据存储层：完成权重参数、输入数据的缓存与读写管理
- 通信交互层：实现FPGA与上位机之间的数据双向传输

## 2. 硬件整体方案
选用通用低成本Xilinx Artix7系列FPGA作为主控硬件，不依赖高端专用加速芯片，依靠纯Verilog逻辑电路搭建加速架构，在满足课程设计实践要求的同时，兼顾硬件成本与资源利用率，适配主流通用FPGA开发板。

## 3. 软件设计方案
1.  使用Verilog HDL完成所有硬件逻辑代码编写，严格遵循模块化编码规范
2.  借助Vivado 2020.2开发环境完成代码编译、综合、布局布线全流程
3.  通过Vivado内置仿真工具完成前期逻辑验证，排查代码逻辑错误后再进行实物调试
4.  配套完整的测试激励文件，支持模块级与系统级双重仿真验证

## 4. 运行整体流程
上位机下发输入数据 → FPGA缓存接收数据 → 硬件并行运算单元处理推理计算 → 结果整理打包 → 串口上传输出至上位机，完成整套LLM推理闭环流程。

## 5. 方案优势
结构清晰易调试、硬件成本低、学习性强、拓展性好，完全符合课程项目设计标准，同时可作为后续边缘端AI推理硬件开发的基础参考方案。
