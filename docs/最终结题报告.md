# 基于FPGA的轻量化大语言模型推理加速器项目结题报告
## 一、项目研究背景与意义
随着大语言模型快速发展，边缘端轻量化部署需求日益增长。传统CPU推理速度慢、功耗高，而FPGA具备可重构、低功耗、并行计算优势，适合大模型推理加速。本项目设计轻量化LLM硬件加速器，实现算子并行运算，提升边缘端推理效率，同时通过文献计量法梳理领域研究现状，为后续研究提供参考。

## 二、研究内容与技术路线
1. 文献计量分析：构建中英文检索式，筛选、清洗文献样本，完成发文量、机构、关键词等统计分析，梳理领域热点。
2. 需求分析：明确功能、性能、环境、约束需求，确定系统整体设计指标。
3. 硬件架构设计：采用模块化分层架构，划分顶层控制、运算加速、数据缓存、串口交互四大模块。
4. Verilog代码开发：完成矩阵乘加、激活函数、数据缓存等核心模块代码编写。
5. 仿真与调试：完成模块级、系统级时序仿真，优化时序问题，最终实现功能稳定运行。

## 三、项目成果
1. 文献计量成果：完成检索式、样本量筛选、数据清洗、统计图表全套分析内容。
2. 硬件系统成果：实现完整FPGA‑LLM推理加速系统，可完成基础大模型算子并行计算。
3. 文档成果：形成需求分析、总体方案、硬件设计、仿真分析、中期报告、结题报告全套规范文档。
4. 项目仓库成果：搭建标准化GitHub项目仓库，文件结构规整，完全满足课程结题交付标准。

## 四、存在不足与改进方向
### 不足
1. 仅实现基础轻量化算子加速，未适配完整大模型网络结构。
2. 串口通信传输速率有限，大数据量交互存在延迟。
3. 暂未完成大规模上板性能实测，缺少完整功耗‑速度对比数据。

### 改进方向
1. 扩展支持更多LLM算子，适配完整轻量化大模型。
2. 优化串口通信，提升数据传输效率。
3. 开展多组上板测试，完善性能与功耗对比实验。

## 五、总结
本项目完成从文献调研、方案设计、代码开发、仿真验证到成果整理的全流程，实现FPGA轻量化大模型推理加速功能，同时规范完成文献计量研究，整体达到课程项目结题要求，为后续边缘端AI硬件开发提供实践基础。
