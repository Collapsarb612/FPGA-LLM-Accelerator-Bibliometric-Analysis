# 基于Python的文献数据清洗说明
## 1. 开发环境
Python3.8及以上版本，依赖pandas数据处理库

## 2. 代码功能
1. 读取数据库导出的原始文献表格数据
2. 根据题名、DOI编号批量剔除重复文献
3. 筛选保留FPGA、大模型硬件加速相关主题文献
4. 统一规整机构名称、关键词表述格式
5. 剔除信息残缺、无研究价值的无效条目
6. 生成清洗完毕的标准化数据集

## 3. 执行流程
1. 导入原始数据源文件
2. 运行清洗逻辑完成数据筛选修正
3. 保存处理后的干净数据
4. 基于最终数据开展发文量、机构、热点统计分析

## 4. 清洗成果
初始检索文献两千篇，经代码自动化清洗筛选后，得到有效研究样本八百余篇，数据规范性满足后续计量分析要求。
